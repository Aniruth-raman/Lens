# Lens mark

The mark combines a sheet with a folded corner and four scan brackets. The indigo sheet details echo the app accent (`#6366F1`). The simple silhouette stays recognizable in the Android themed icon.

Rejected directions:

- **Camera aperture:** reads as a camera app and repeats the old launcher mark rather than the document workflow.
- **Standalone page outline:** says “document” but not “scan”; the brackets make the capture action clear at small sizes.

`logo-mark.svg` is the full mark; `logo-mark-monochrome.svg` is the single-colour Android themed-icon source.

Use the existing Material Icons `document-scanner` glyph for the Gallery scan button. It names the scan action directly and is already available through the installed icon package.
